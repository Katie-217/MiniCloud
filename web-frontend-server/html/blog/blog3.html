Quan sát hệ thống bằng số liệu

Node Exporter cung cấp số liệu, Prometheus thu thập theo thời gian, Grafana hiển thị biểu đồ. Ba thành phần giúp theo dõi CPU, bộ nhớ và lưu lượng mạng khi phục vụ yêu cầu.

CPU và lưu lượng mạng được biểu diễn bằng tốc độ thay đổi counter theo thời gian. Một counter tích lũy không trực tiếp cho biết hệ thống đang bận bao nhiêu.

Trên Docker Desktop, CPU và RAM phản ánh Linux VM; network tùy namespace của exporter. Không diễn giải những số liệu này thành mức sử dụng của toàn bộ Windows. Dashboard cần có dữ liệu thực và query đúng.
